# Fatih Günalp — Portfolio / Portföy

Personal portfolio for engineering systems, .NET and AI orchestration. A static English/Turkish website, with no build or dependencies required.

Mühendislik sistemleri, .NET ve AI orchestration odaklı kişisel portföy. İngilizce ve Türkçe dil desteğine sahiptir; derleme veya ek bağımlılık gerektirmez.

## Publish / Yayın

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Only selected public repositories are linked. / Yalnızca seçilmiş public repository bağlantıları kullanılır.
